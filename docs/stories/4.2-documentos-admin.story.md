# Story 4.2 — Documentos do check-in no dashboard

**Status:** InReview
**Autorização:** usuário solicitou em 02/11/2026: “todos os documentos, termos e atestados devem ficar disponíveis no dashboard administrativo, com possibilidade do administrador fazer exportação em PDF dos documentos.”
**Origem:** itens “Fora do escopo” da Story 4.1 (painel administrativo para consultar termos e atestados; PDF do termo assinado).

## Acceptance Criteria

- [x] Menu do dashboard ganha “Documentos” (`/admin/documentos`), só para admin ativo.
- [x] Lista todos os atletas aprovados com situação (confirmado/pendente), equipe, box, competição, categoria, data da assinatura e alertas (PAR-Q com “Sim”, menor de idade).
- [x] Busca (atleta, equipe, box, categoria; sem acentos/maiúsculas) e filtros por competição e situação; resumo com confirmados, pendentes, PAR-Q com “Sim” e menores.
- [x] Página do atleta mostra identificação, respostas do PAR-Q, assinaturas (participante e responsável), registro da assinatura eletrônica (e-mail confirmado, data, IP, navegador), texto integral do termo aceito e o atestado (pré-visualização de imagem, abrir e baixar o original) por URL assinada de 10 min.
- [x] “Baixar PDF” por atleta: termo preenchido + PAR-Q + assinaturas + registro + atestado anexado (PDF incorporado página a página; JPG/PNG/WEBP como imagem; formatos não suportados viram página de aviso).
- [x] Exportação em lote do filtro atual: “PDF dos termos” e “PDF com atestados”, com capa/índice e paginação; até 200 atletas por arquivo.
- [x] PDFs acima de 4 MB são entregues por link temporário (bucket privado `admin-exports`, criado sob demanda; arquivos com mais de 1 h são apagados).
- [x] Testes do gerador de PDF; `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` executados.
